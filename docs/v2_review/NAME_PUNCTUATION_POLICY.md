# Proper-name punctuation policy

- Proper-name internal apostrophes and hyphens are part of the name and must be preserved in Korean.
- Khajiit-style M'... names use 므'..., not 엠..., 음..., or 마'....
- Example: M'key → 므'케이; M'raaj-Dar → 므'라즈-다르. Exception: M'aiq → 마'이크.
- Place-name example: Stros M'Kai → 스트로스 므'카이.
- If a proper name contains source hyphens, retain hyphenated structure in Korean instead of silently removing it.
- English possessive 's is grammatical, not internal name punctuation; translate possession naturally in Korean.
- Apply this only to proper names/titles, not ordinary English contractions.
