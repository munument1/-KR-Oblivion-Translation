# 메인 메뉴 문자 깨짐 — 2026-10-01

사용자가 메인 메뉴부터 `ei`처럼 깨진다고 보고했다. 같은 시험 프로필과 번역 파일을 유지한 채 MO2 실행 항목만 비교하여 재현하고 복구했다.

| 실행 | MO2 실행 항목 | 확인 결과 |
|---|---|---|
| J, 22:50:04 KST | `obse_loader` | 메뉴가 `ì`, `ë` 등으로 깨짐. 게임 모듈에는 xOBSE와 usvfs가 있지만 obCJK가 없음. OBSE 로그에 플러그인 검사/로드가 없고 obCJK 로그는 이전 실행 시각 그대로임. |
| K, 22:53:10 KST | `Oblivion` | obCJK, xOBSE, usvfs 및 UOP DLL이 게임에 로드됨. 새 OBSE 로그에 obCJK loaded correctly, 새 obCJK 로그에 UTF8와 훅 초기화 기록. 새로하기/불러오기/환경설정/제작진/종료가 한글로 표시됨. |

이 환경에서 깨진 실행의 직접 원인은 obCJK 플러그인이 로드되지 않아 UTF-8 문자가 원본 폰트로 처리되는 것이다. `obse_loader`의 초기화가 MO2 VFS 연결보다 먼저 진행되는 순서 문제는 로그에 근거한 후보이며, 내부 호출 순서까지 추적하여 확정한 것은 아니다. 번역 파일·위치명 파일·폰트 설정 변경 없이 실행 항목 변경만으로 메뉴 표시가 복구됐다.

MO2의 선택을 `Oblivion`으로 바꿨다. 이 항목은 시험 프로필의 기존 force-load 설정으로 xOBSE를 함께 로드하므로, 이 설치에서는 별도로 `obse_loader`를 선택할 필요가 없다. Default 프로필과 실제 게임 Data에는 쓰지 않았다.

실행 J는 메뉴 대기 상태에서 시험 프로세스를 종료했다. 실행 K는 사용자의 창 입력이 감지되어 추가 입력이나 강제 종료 없이 정상 한글 메뉴 상태로 남겼다. 새 게임·본문·저장/재로드 성공을 이 결과에 포함하지 않는다.
