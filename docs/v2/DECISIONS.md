# v2 Decision Log

이 파일은 장기적으로 유지해야 하는 확정 결정을 기록한다.
기존 결정을 바꿀 경우 삭제하지 말고 새 결정 ID로 대체 사유를 남긴다.

## D-001 — v1.0.2 동결
- 상태: 확정
- 날짜: 2026-09-29
- 결정: v1.0.2는 릴리즈 기준본으로 동결한다.
- 이유: v2 신규 번역과 v1 유지보수를 섞으면 기준점이 흔들리고 회귀 검증이 어려워진다.

## D-002 — v2 용어 기준은 최신 Skyrim SST
- 상태: 확정
- 날짜: 2026-09-29
- 결정: 사용자가 확보한 최신 Skyrim SST를 우선 기준으로 사용한다.
- 이유: Elder7 자료보다 최신 시리즈 용례를 반영하기 위함.
- 예외: Oblivion 문맥과 충돌하는 경우 자동 적용하지 않고 Sol 검수.

## D-003 — 원문은 정품 영문 게임에서 신규 추출
- 상태: 확정
- 날짜: 2026-09-29
- 결정: v1 한국어 패치에서 영어 원문을 역추출하지 않는다.
- 이유: 기존 번역 흔적과 누락/오염을 신규 파이프라인에 전파하지 않기 위함.

## D-004 — RACE/FULL 영문 유지
- 상태: 확정
- 날짜: 2026-09-29
- 결정: RACE/FULL은 번역하지 않는다.
- 이유: `Sound\Voice\<plugin>\<Race Name>` 경로 호환 및 음성/자막 안정성.

## D-005 — 메뉴 GMST 926개를 플레이어 노출 마스터로 사용
- 상태: 확정
- 날짜: 2026-09-29
- 결정: v1.0.2에서 대조한 926 GMST / 924 고유 EDID를 v2 메뉴 범위의 마스터 목록으로 활용한다.
- 결정: 최종 배포는 별도 메뉴 ESP가 아니라 Oblivion.esm 직접 통합 방식을 유지한다.

## D-006 — 문맥 기반 번역 단위
- 상태: 확정
- 날짜: 2026-09-29
- 결정: 단순 영어→한국어 문자열 목록으로 번역하지 않는다.
- 결정: INFO는 화자/퀘스트/대화 문맥을 포함한다.
- 결정: BOOK/NOTE는 전체 문서를 한 단위로 번역한다.
- 이유: 줄 단위 기계번역으로 인한 문체/대명사/연결성 붕괴 방지.

## D-007 — Gemini는 초안, Sol이 최종 확정
- 상태: 확정
- 날짜: 2026-09-29
- 결정: Gemini 출력은 자동으로 빌드 입력에 들어가지 않는다.
- 이유: 의미 보존, 용어 일관성, 문맥, 포맷 안전성을 영어 원문과 직접 대조해야 한다.

## D-008 — 비밀값은 Git/채팅/로그에 기록 금지
- 상태: 확정
- 날짜: 2026-09-29
- 결정: API 키 값은 어떤 형태로도 저장소/대화/로그에 출력하지 않는다.
- 허용: 키 슬롯 번호, 쿼터 오류 코드, 배치 ID, 요청 통계.

## D-009 — v2 문맥 자체도 Git으로 관리
- 상태: 확정
- 날짜: 2026-09-29
- 결정: 작업 종료 시 `PROJECT_STATE.md`, `NEXT_SESSION.md`, 필요 시 날짜별 `SESSION_LOG`를 갱신한다.
- 이유: 채팅 길이 제한이나 새 세션 전환 시 문맥 혼동을 최소화하기 위함.
