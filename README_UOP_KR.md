# Unofficial Oblivion Patch 한국어 ESP 오버레이

대상 원본: Unofficial Oblivion Patch **3.5.9a**, Unofficial Shivering Isles Patch **1.6.2**, Unofficial Oblivion DLC Patches **v27**. 이 압축파일은 위 버전의 ESP 11개에 한국어 문자열만 적용한 MO2 오버레이입니다. 원본 패치의 다른 파일과 기능 레코드는 원본 모드에서 계속 읽습니다.

## MO2 설치

1. 위 세 영문 원본 패치를 먼저 설치하고 활성화합니다. 설치한 공식 DLC에 해당하는 패치 ESP만 활성화합니다.
2. 이 ZIP을 새 MO2 모드로 설치해 압축파일 최상위의 ESP 11개가 모드 최상위에 오도록 합니다. 이 한글 모드를 영문 원본 패치 세 모드보다 **높은 우선순위**에 둡니다. 플러그인 이름과 로드 순서는 영문 패치와 같습니다.
3. `Optional` 폴더의 두 ESP는 해당 영문 선택 패치를 실제로 사용하는 경우에만 같은 이름의 ESP를 한글 모드 최상위로 옮깁니다. `UOP Vampire Aging & Face Fix.esp`에는 번역 대상 문자열이 없어 포함하지 않았습니다.
4. 본편 한글 번역 설치기의 최신 출력 `Oblivion_KR_Mod`도 활성화합니다. 한글 폰트 설정은 그 설치기의 `FONT_SETTINGS.txt`를 따릅니다.

## 적용과 검증

- 최신 원본 ESP와 이전 한글 ESP를 레코드 종류·FormID·필드 순서·원본 영어 바이트로 대조해 번역 문자열만 다시 썼습니다. 이전 통합판의 본편 레코드를 패치에 복사하지 않았습니다.
- `CELL/FULL`, `WRLD/FULL` 장소명 1,410건은 영어로 유지했습니다. 구형 한글 바이트가 장소명에 들어가면 일반 저장 파일 생성이 실패할 수 있었기 때문입니다.
- `Unofficial Shivering Isles Patch.esp`의 `Fellmoor` 로딩 문구 1건은 기존 한글패치의 같은 FormID·EditorID 번역을 적용했습니다. 최신 원문에서 마침표 뒤 공백만 달라진 것을 확인하고 정확한 새 원문 바이트로 검증했습니다.
- 출력 14개 ESP(기본 11개와 선택 2개, 무번역 선택 1개)는 각각 원본과 레코드·그룹 식별자 및 컴파일된 스크립트 해시가 같습니다. ZIP에는 번역이 없는 선택 ESP 1개를 제외한 13개를 넣었습니다. 검증 수치와 SHA-256은 `release_audit.json`에 있습니다.
- 이 검사는 파일 구조와 문자열 대조입니다. 새 ESP 조합의 게임 안 대화·선택지·일반 저장은 사용자가 MO2에서 확인해야 합니다.

이미 설치한 오래된 `Unofficial ...-KR` 모드를 함께 켜 두면 이 ZIP의 ESP가 우선 적용되지 않을 수 있습니다. 오래된 한글 모드는 끄고 이 오버레이 하나만 사용하세요.
